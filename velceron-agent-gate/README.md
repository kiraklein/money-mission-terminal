# Velceron Agent Gate

Machine-consumable governance gate for autonomous agents.

**API:** `POST /api/velceron/v1/evaluate`  
**MCP:** `POST /api/velceron/mcp`  
**OpenAPI:** `GET /api/velceron/openapi`  
**Health:** `GET /api/velceron/health`

The engine returns `allow`, `review`, or `block`, with machine-readable reasons, required controls, audit metadata, and a billing unit.

Target commercial price: **US$0.20 per evaluation**.

Current public surface is demo-only until a live x402 receiving wallet/facilitator is connected. Do not treat the engine as a legal opinion or regulatory certification.
